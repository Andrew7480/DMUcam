# Tarea DM Ucam

Práctica de la asignatura Aplicaciones para Dispositivos Móviles de la Universidad Católica San Antonio de Murcia (UCAM).

El objetivo de esta tarea es recrear diferentes pantallas de una aplicación móvil utilizando Kotlin y Jetpack Compose, aprovechando sus componentes nativos para construir interfaces de usuario de forma declarativa.
